# Mohamed Ekramy Portfolio

An editorial portfolio of seven projects selected by Mohamed: Masahati, HealthGuard, PUBG Language Transpiler, AI Search & Game Algorithms, College Attendance System, Librarium, and MiniFAT.

## Run

```sh
python -m http.server 8775
```

Open http://localhost:8775. No build step is needed. Project notes are embedded in `index.html`; `project-data.json` contains the matching source data.

## Design

Warm paper, charcoal, orange and lime; project-specific illustrations; a Masahati design preview using fictional data; accessible project dialogs, filtering, mobile navigation, and reduced-motion support. No unavailable demo is represented as live.

The visual workflow follows the local `.agent` UI/UX, frontend and visual validation guidance. The site remains a static deployment on Vercel.
